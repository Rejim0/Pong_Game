# Pong Arcade Game 🎮

I built this Pong game using Python and the Turtle library while learning object-oriented programming.

This project helped me understand how game logic works step by step, especially movement, collision, and score tracking.

## How it works

- The ball moves across the screen and bounces off the top and bottom walls
- When the ball hits a paddle, it changes direction
- If a player misses the ball, the other player gets a point
- The game speed increases after each paddle hit

## Controls

- Right Paddle:
  - Up Arrow → move up
  - Down Arrow → move down

- Left Paddle:
  - W → move up
  - S → move down

## Files

- main.py → runs the game
- ball.py → handles ball movement
- paddle.py → controls paddles
- score.py → tracks score
